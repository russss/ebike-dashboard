# ADO e-bike reverse-engineering

This repository contains the results of reverse engineering my ADO e-bike (Air 20 Pro).

You probably want to read the [Bluetooth protocol documentation](./docs/ado-ble-protocol.md).

[`dashboard/`](./dashboard/) is a live telemetry dashboard (Lit + Vite + TypeScript) built on top
of that protocol.

## LLM warning

This repository is substantially LLM-assisted.
